# 文脈による字形選択と異体字シーケンス

馬酔木明朝（バージョン2.000）では、「雄弁・弁別・花弁」の「弁」を、それぞれ「辯・辨・瓣」の字形で表示できます。「弁別」を「辨別」の字形で表示した場合も、コピーすると入力時の「弁別」が得られます。

## 前後の文字に応じた表示

OpenTypeの文脈依存字形機能（`calt`）が有効なアプリでは、登録した文字の並びに応じて字形を選びます。「花弁」なら「花」の直後の「弁」に「瓣」の字形を選びます。「雄弁」の「辯」は「弁」の既定の字形です。表の「通常」欄に、既定の字形を示します。 [OpenTypeの `calt` 仕様](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ae#tag-calt)

## 入力した漢字自体の字形を指定する（IVS）

馬酔木明朝では、「弁」は通常「辯」、「余」は通常「餘」の字形で表示します。「弁」や「余」自体の字形が必要な場合は、入力する漢字の直後に字形指定用の文字（異体字セレクタ）を置きます。漢字と異体字セレクタの組を、異体字シーケンス（IVS）と呼びます。馬酔木明朝でこの指定ができるのは、表に示す17組です。

「弁」「余」自体の字形を指定するには、表の「IVS（コピー用）」欄から `弁󠄀` または `余󠄀` をコピーして貼り付けます。どちらの組も、漢字の直後に U+E0100 が続きます。対応アプリでは、IVSの指定が `calt` より優先します。

### 同音の別字を表示する例

「台頭」を「擡頭」、「台風」を「颱風」と表示する規則もあります。同音の別字による表記は、一部の語に限って補足的に登録しました。

### 表の語句で目的の字形が出ないとき

アプリで `calt` を有効にし、表の文字列を同じフォント・書式で入力します。「花 弁」と間に空白を挟むと、「花［弁］」の規則に一致しません。アプリが語句を途中で分けて処理する場合も、前後の文字をひと続きに参照できず、規則が適用されないことがあります。

表の規則に当てはまる語句がなく、IVSによる指定もない場合は通常の字形になります。文書の文字として「辨」や「瓣」を保持するには、その字を直接入力します。

### 複数の規則が当てはまるとき

対象字の前後に指定した文字数の合計が多い規則を優先し、同数なら登録順で決めます。「天台風」の「台」には「天［台］」と「［台］風」が当てはまります。先に登録された「天［台］」の規則が適用され、「台」の字形になります。「台台」と「芸芸」の規則では、2字とも同じ字形になります。

配布ZIPの `編集資料/文脈とIVSの規則.json` で、規則の登録順と字形の割り当てを確認できます。
