# 補完した漢字の字形選定と照合記録

[漢字の字形選定と照合記録](glyph-differences.md)のうち、一点明朝正字 v1.1 から同じ符号位置の字形を取得できなかった64字の採用形を掲載します。字書や用例から表示に適した既存の字形を確認できる場合はその字形を採用し、個別に構成を確かめた字は、檢校表や推薦形體表に照らして筆画の形を定めます。
