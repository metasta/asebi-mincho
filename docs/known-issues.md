# 既知の不具合と対処法

## Mac版Wordの縦組みで三点リーダが左に寄る

Mac版Wordで馬酔木明朝（バージョン2.000）を縦組みにすると、三点リーダ `…`（U+2026）が列の中心より少し左に寄る場合があります。横組み用の字形を回転して表示する場合に生じるずれです。

中央に置くには、縦組み用の三点リーダ `︙`（U+FE19）を入力します。2字分なら `︙︙` です。横組みと縦組みが混在する文書では、縦組みの箇所にこの文字を指定します。 [Unicode 17.0 §6.2「Vertical Ellipsis」](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-6/)
